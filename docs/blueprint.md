# **App Name**: LumensForge

## Core Features:

- Secure User Authentication: A combined Login/Signup page featuring email/password and social login (Google optional). Includes a hidden admin login that redirects to the Admin Dashboard upon successful authentication.
- AI-Enhanced Product Descriptions: An AI-powered tool for product managers to generate and refine detailed, engaging product descriptions and specifications based on basic product inputs (name, category, key features).
- Dynamic Product Catalog Display: Browse products across categories (e.g., Lighting, Gadgets) via a grid layout on the Shop page, with filtering options for category, price range, and availability. Features a prominent hero section on the Home page and product cards displaying image, name, price, and quick add-to-cart buttons.
- Detailed Product Views: Individual product pages showcasing large images, comprehensive descriptions and specifications (AI-enhanced), pricing, stock availability, and 'Add to Cart'/'Buy Now' functionalities.
- Shopping Cart & Checkout System: Manage cart items with quantity controls, view total prices, and complete orders through a simple checkout process including address details and a mock payment/Cash on Delivery option.
- Admin Product & Order Management: Admin dashboard features to add, edit, and delete products (name, price, description, category, stock, image upload). Additionally, manage orders by viewing all customer orders and updating their status (Pending, Processing, Shipped, Delivered).
- User Dashboard & Order History: A personalized user dashboard allowing customers to view and update profile information, manage saved addresses, and track their order history with real-time status updates.

## Style Guidelines:

- A dark theme for a sleek, futuristic aesthetic. The background will be a very dark, slightly bluish charcoal (#141B1F). Interactive elements and key information will use a vibrant electric blue (#0099FF), chosen for its energetic and tech-inspired feel. Highlighting elements and secondary glows will utilize a bright aqua accent (#BFFFFF) to create visual contrast and neon-like effects.
- All text will use 'Inter', a grotesque-style sans-serif font. Its modern, machined, and neutral aesthetic provides a sharp, minimalistic look suitable for both headlines and body text in a tech-inspired interface.
- Clean, outlined, vector-based icons that align with a futuristic and tech-inspired theme. Favor simplicity and precision over ornate designs.
- A responsive design prioritizing a clean content hierarchy for optimal viewing on both desktop and mobile devices. Key sections will feature bold taglines, carousel displays, and organized product grids. Includes a dedicated space for a logo at the top of the interface.
- Smooth transitions for page navigation, subtle hover effects on interactive elements like buttons and product cards, and 'glowing' visual feedback for key actions. Implement loading animations and skeleton screens for a polished user experience during data fetching.
